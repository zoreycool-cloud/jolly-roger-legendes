# Jolly Roger — Kit audio QR code

## 1. Préparer les fichiers
Exporter les 5 légendes au format MP3 puis les renommer exactement :

- wako.mp3
- diable.mp3
- calypso.mp3
- sirenes.mp3
- kraken.mp3

Déposer les 5 fichiers dans le dossier `audio`.

## 2. Tester sur votre ordinateur
Ouvrir `index.html`.
Pour un test complet du son, il est préférable de tester après mise en ligne.

## 3. Mise en ligne gratuite avec GitHub Pages
1. Créer un compte GitHub.
2. Créer un nouveau dépôt nommé par exemple `jolly-roger-legendes`.
3. Importer tous les fichiers et dossiers du kit.
4. Ouvrir `Settings` > `Pages`.
5. Dans `Build and deployment`, choisir `Deploy from a branch`.
6. Choisir la branche `main` et le dossier `/root`.
7. Enregistrer.
8. GitHub fournit ensuite l'adresse publique du site.

L'adresse ressemblera à :
https://VOTRE-NOM.github.io/jolly-roger-legendes/

## 4. Adresses des 5 QR codes
Une fois le site publié :

- Wako : https://VOTRE-NOM.github.io/jolly-roger-legendes/wako/
- Diable : https://VOTRE-NOM.github.io/jolly-roger-legendes/diable/
- Calypso : https://VOTRE-NOM.github.io/jolly-roger-legendes/calypso/
- Sirènes : https://VOTRE-NOM.github.io/jolly-roger-legendes/sirenes/
- Kraken : https://VOTRE-NOM.github.io/jolly-roger-legendes/kraken/

Générez ensuite un QR code distinct pour chacune de ces cinq adresses.

## 5. Important avant impression
Ne faites imprimer les QR codes définitifs qu'après :
- publication du site ;
- test des 5 pages ;
- test des 5 audios ;
- scan réel des QR codes sur téléphone.

## 6. Modifier une légende plus tard
Pour remplacer un enregistrement sans changer le QR code :
1. garder exactement le même nom de fichier ;
2. remplacer uniquement le MP3 dans le dossier `audio` ;
3. republier la modification.

Le QR code continuera à fonctionner.
