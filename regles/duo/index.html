PARTIE EN DUO

Mode Alliance totale — toute la partie est pensée pour être jouée en binôme.

01

ALLIANCE TOTALE

Dans ce mode, le binôme n’est pas une alliance temporaire : les deux joueurs forment une équipe pour toute la partie.

VICTOIRE EN BINÔME

La victoire est commune aux deux partenaires. Les conditions détaillées de victoire du mode Duo seront intégrées dans cette rubrique avec les autres adaptations propres à ce mode.

RESSOURCES PARTAGÉES

Les ressources peuvent être partagées de manière permanente entre les deux partenaires, selon les règles spécifiques du mode Alliance totale.

LIEUTENANTS PARTAGÉS

Les Lieutenants peuvent être répartis entre les deux navires de façon permanente pendant la partie. Leurs pouvoirs, Améliorations et Combinaisons devront être calculés selon leur emplacement actuel.

MODE EN CONSTRUCTIONLa mécanique complète du mode Duo sera développée séparément afin d’adapter chaque chapitre du jeu à une véritable jouabilité en binôme, sans copier simplement les règles du mode classique.
